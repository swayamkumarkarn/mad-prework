Quick guide

                  
A few things to know while testing.

                

              

            

            

              
A confirmed RSVP takes a spot; guests beyond the event capacity are waitlisted. Cancelling a confirmed RSVP promotes the next waitlisted guest.

              

              
Each RSVP request uses an idempotency key. Reuse the same key to safely retry the same request; use a new key for a different request.

              

              
The API and PostgreSQL must be running. Start them with npm run dev and your database setup.
